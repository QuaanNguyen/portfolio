# Legacy portfolio archive

This folder preserves the previous portfolio design and its source-only features.
Nothing in this folder is imported by the active application or included in the production bundle.

The archive contains the guestbook comment feature, League Impostor, the previous portfolio page, supporting components, hooks, data access, styles, and original assets.
The optimized WebP champion artwork is retained in `assets/champions-webp` for a future revival.
The original champion images remain in `assets/LolChampions` as archival source material.

To revive a feature, move the necessary module into the active application, reconnect its route deliberately, and verify its dependencies and data access before release.
